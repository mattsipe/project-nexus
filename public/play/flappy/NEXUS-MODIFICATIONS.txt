THE ASSET PROBLEM, AND WHAT WAS DONE ABOUT IT
---------------------------------------------

floppybird is Apache-2.0, and that licence covers Nebez Briefkani's code. It
does not — and cannot — cover the contents of its assets/ directory, which is
the original Flappy Bird sprite and sound set: bird.png, pipe-up.png,
pipe-down.png, the four medals, the scoreboard, the digit glyphs, and five
.ogg sound effects. The repository's own README describes the project as a
"vintage knockoff". Dong Nguyen never granted redistribution rights to that
material, and an Apache-2.0 licence on a repository grants nothing in respect
of material its author did not own.

Nexus hard rule 2 forbids self-hosting a game or its art without a verified
redistributable licence. So:

  * EVERY file in assets/ was deleted before anything was committed. None of
    the original artwork or audio is present in this bundle or in this
    repository's history.

  * A complete replacement sprite set was drawn for Nexus and is generated by
    scripts/make-flappy-art.ts, at exactly the dimensions css/main.css and
    js/main.js expect. Re-run that script to regenerate assets/.

What was kept is the code, and the code is the reason for vendoring this
particular recreation: its gravity, flap impulse, pipe gap, pipe spacing and
scroll speed are the faithful part, and they are untouched. The game plays
exactly as upstream plays. It just looks like Nexus.

Changes
-------

1. assets/ — replaced wholesale, as above. assets/README-NEXUS.txt records
   the provenance beside the files.

2. js/main.js — the five buzz.sound objects are replaced by a single silent
   stub with the same surface (play/stop/setVolume/bindOnce). The death
   sequence chains showScore() off bindOnce("ended"), so the stub still fires
   that callback, after roughly the length of the clip it replaces — the beat
   between dying and seeing the scoreboard is unchanged. No game logic was
   touched.

3. js/buzz.min.js — removed. Nothing loads audio any more.

4. index.html — removed a deferred Umami analytics script pointing at
   yummy.nebez.dev with a site id attached. Nexus carries no analytics.

5. index.html — the credit line read "original game/concept/art by dong
   nguyen". The art is no longer his, so the line now reads "original game
   concept by dong nguyen", and a line was added stating that the artwork is
   original to Project Nexus. Nebez Briefkani's credit and the link to the
   upstream project are untouched.

6. css/main.css — two colours retoned: the sky was #4ec0ca (the original
   game's daylight cyan) and the ground was #ded895 (its sand). Both fill the
   area around the new sprites, so both had to match them. No layout,
   geometry or timing rule was changed.
